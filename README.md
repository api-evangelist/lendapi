LendAPI is a no-code / low-code loan origination and digital account-opening platform for banks, credit unions, fintechs and embedded-finance programs. Its Product Studio lets teams assemble a lending product -- application form, underwriting logic, pricing and servicing -- without writing code, backed by a versioned decision engine, a versioned pricing engine, DocAI document processing, UnderwriteAI and ARC AI scoring, KYC/KYB verification, two-way SMS, virtual cards and the Embarc loan management system. A marketplace of pre-integrated data partners covers credit bureaus, identity verification, open banking, cash-flow analytics and income verification. The REST API documented at developer.lendapi.com exposes the same primitives programmatically: create and advance applications, run decisions and pricing, manage tenant-defined variables and sub-tenants, pull bureau credit reports, compute amortization schedules and score credit risk. LendAPI is SOC 2 Type 2 attested and serves use cases across point-of-sale finance, buy-now-pay-later, auto lending, fix-and-flip, retail in-store lending and embedded finance.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for LendAPI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
